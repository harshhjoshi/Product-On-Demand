# 📦 Product-On-Demand

**Product-On-Demand** is a dynamic and scalable mobile application built with **React Native** that allows users to **browse, request, and receive customized products or services** based on their specific needs — all in real time.

This app demonstrates advanced mobile development skills, clean architecture, and user-focused design, making it a perfect showcase for on-demand service solutions.

---

## 🚀 Key Features

- 🔍 **Browse Products & Services**  
  Explore a catalog of customizable products and services.

- 🛒 **On-Demand Ordering**  
  Submit detailed product/service requests with specifications.

- ⏱️ **Real-Time Status Tracking**  
  Track the progress of your orders in real time.

- 🧾 **Order History & Reordering**  
  View past orders and place reorders quickly.

- 📲 **Push Notifications**  
  Receive live updates about your order status.

- 🔐 **Secure Authentication**  
  Role-based access with secure login/signup.
